## About

NorthFrame is my freelance web development portfolio and business website.

It showcases my services, projects and approach to building modern, responsive and SEO-friendly websites.

The goal is simple: create fast, elegant and conversion-focused websites that help businesses grow online.

## Features

- Responsive design
- SEO-friendly structure
- Smooth animations
- Modern UI
- Contact form
- Portfolio section
- Services presentation

## Tech Stack

- Laravel
- PHP
- Tailwind CSS
- Vite
- JavaScript

## Installation

```bash
git clone https://github.com/a-pade/northframe.git

cd northframe

composer install

cp .env.example .env

php artisan key:generate

npm install

php artisan migrate

npm run dev

php artisan serve
```

## Production

```bash
npm run build
```
